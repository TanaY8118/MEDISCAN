## 3. OPERATIONAL PROTOCOLS

### 1. The "Golden Rule" of Data Access
**ALL** data access must be scoped to the authenticated user.
- **Backend:** `repository.findByUserId(currentUser.getId())` is mandatory.
- **Frontend:** Ensure API calls handle `401 Unauthorized` gracefully.

### 2. Migration Protocol
We do **NOT** rely on Hibernate to create tables.
To change the DB schema:
1.  Create a new SQL file in `backend/src/main/resources/db/migration` (e.g., `V003__description.sql`).
2.  Run the migration profile to apply changes.
3.  Update the Java Entity to match.

### 3. Secrets Management
- **NEVER** commit secrets to Git.
- Use `.env` for local development.
- Production deployments inject secrets via environment variables in the container runtime.
