## Conflict Resolution Rules

### File Conflicts
- Person 1 NEVER edits .sql files
- Person 2 NEVER edits .java files
- Person 3 NEVER edits backend/** files
- Person 4 ALWAYS uses separate tests/ folder

### API Contract Changes
- Once Person 1 commits v1 DTOs (Day 1 End):
- FROZEN - No changes to field names/types
- If change needed: Create v2, keep v1 intact

### Dependency Changes
- Only Person 2 modifies:
- backend/pom.xml (Maven dependencies)
- mobile/package.json (after Person 3's initial setup)

Process:
1. Person needs dependency
2. Request in Slack/Teams
3. Person 2 adds it
4. Person 2 commits
5. Requester pulls
